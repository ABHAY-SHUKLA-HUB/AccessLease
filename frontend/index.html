Company-Grade Contractor Access & Offboarding Governance

AccessLease governs temporary contractor access lifecycle across enterprise resources, ensuring every grant is strictly owned, approved, time-bound, reviewable, and verifiably revoked.

Owned

Internal business sponsors and system owners are permanently assigned to every contractor entitlement.

Approved

Explicit, audited approval workflows eliminate undocumented and out-of-band access grants.

Time-Bound

Deterministic lease periods with automated termination timestamps prevent lingering access.

Reviewable

Periodic recertification and complete audit trail ready for enterprise compliance examinations.

Verifiably Revoked

Automated deprovisioning engines confirm and log cryptographic and operational revocation proofs.

Authentication & Identity Architecture

OAuth 2.0 Authorization Code Flow with PKCE: Front-channel identity is securely authenticated via Microsoft Entra ID (MSAL Browser). All API requests attach cryptographic Bearer tokens verified on the backend using Microsoft public signing keys (JWKS RS256). Stable Entra Object IDs (oid) map deterministically to application users in dbo.users.
