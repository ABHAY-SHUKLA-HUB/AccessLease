Foundation Architecture Overview

Core technology stack and technical foundation powering the AccessLease governance platform.

Relational Database

15 Normalized Tables in 3NF

Enforced foreign keys, check constraints, indexed lookup tables, and ACID transaction safety across all governance entities.

Authentication Subsystem

Microsoft Entra ID (OAuth 2.0 PKCE)

Cryptographic RS256 JWT validation against public tenant JWKS endpoints with zero secret leakage and role-based access control.

Backend API Service

Azure Functions v4 (Node.js 22)

Serverless HTTP triggers, standardized API response envelopes, structured security middleware, and correlation ID tracking.

Frontend Architecture

Pure Vanilla JavaScript Client (ES6+)

Zero external framework bloat, accessible DOM interaction patterns, centralized API client, and MSAL Browser authentication.

Database Engine

Microsoft SQL Server & Azure SQL

Dual compatibility with local development environments and managed cloud Azure SQL Database with Managed Identity authentication.
