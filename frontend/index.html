Foundation Phase Rebaselined

Application Foundation & Governance Engine Readiness

AccessLease governs temporary contractor access across enterprise resources, ensuring every grant is strictly owned, approved, time-bound, reviewable, and verifiably revoked.

Owned

Permanent business sponsors and technical system owners assigned to every grant.

Approved

Multi-stage approval workflows eliminate undocumented or out-of-band access grants.

Time-Bound

Deterministic lease periods with automated expiry prevent lingering contractor access.

Reviewable

Periodic access recertification with tamper-evident audit history for compliance exams.

Verifiably Revoked

Automated revocation engine validates cryptographic and directory deprovisioning proofs.

Current Implementation Status (Step 00 Rebaseline)

  • Relational Database: 15 normalized tables in 3NF deployed and verified in Microsoft SQL Server / Azure SQL.
  • Cloud Security: Microsoft Entra ID OAuth 2.0 PKCE authentication with RS256 token verification.
  • Full-Stack Integration: Azure Functions v4 REST backend communicating with Vanilla JavaScript client.
  • Upcoming Business Modules: Contractor CRUD, Resource Catalogue, Access Requests, and Revocation scheduled in subsequent steps.
